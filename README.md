# Mammography Model Robustness Study

## Project overview
This project evaluates how image-quality variations affect deep-learning models for breast cancer detection in mammography images. We will compare model performance on original images and images altered with controlled variations such as noise, blur, reduced contrast, and lower resolution.

## Research question
How do controlled image-quality variations affect the performance of selected deep-learning models for breast cancer detection in mammography images?

## Proposed dataset
CBIS-DDSM is the proposed primary dataset. The group will confirm access, labels, and permitted use before experiments begin. INbreast may be considered for additional evaluation if access and time allow.
